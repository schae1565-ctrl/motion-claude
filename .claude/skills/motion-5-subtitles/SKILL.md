# 모션그래픽 5단계: 자막

대본(글)이 이미 있는 모션그래픽 쇼츠에 쓴다. 말을 글자로 옮겨야 하는 촬영 영상은 `video-edit-4-captions-render`를 따른다.

## 구성

- `src/shared/ui/SubtitleLine.tsx`: 자막 한 줄. 어두운 갈색 바탕(`theme.text`) + 흰 글자(`theme.onAccent`), 62px, 굵게, 둥근 모서리, `wordBreak: keep-all`. 위치는 `top: 1420`(1920px 기준 약 74~82%)이다.
- `src/videos/<slug>/content.ts`의 `narration`: 장면별 나레이션 문장 배열 (`voice-lines.json`과 같게).
- `src/videos/<slug>/Subtitles.tsx`: 자막 시간 계산과 표시. 메인 컴포넌트의 `ThreeCanvas`(또는 2D 씬) **뒤에** `<Subtitles />`를 둬서 맨 위에 보이게 한다.

## 시간 계산 규칙

1. 장면의 시작 프레임들(`timeline.ts`의 `starts`)을 장면 목록으로 만든다.
2. 장면 구간 = `[이 장면 시작, 다음 장면 시작 − 6프레임]` (문장이 끝난 뒤 쉬는 시간).
3. 장면 문장을 `.`, `?`, `!`, `…` 단위로 나누고, 구간을 **글자 수(한글·숫자·영문) 비율**로 나눠 각 자막의 시작·길이를 정한다.
4. 마지막 자막은 구간 끝 + 3프레임까지 보여준다.
5. 이 시간은 **추정값**이다. 전사(whisper)로 단어 시간을 얻으면 그 값으로 바꾼다 (`motion-3-audio-timing`).

## 넣지 않는 자막

- 화면에 같은 글자가 이미 나오는 문장은 자막으로 중복하지 않는다. 예: 안내 문구("자식은 이렇게 들어요.", "대신 이렇게요.")는 `ON_SCREEN` 집합에 넣어 거른다.
- 마무리 질문처럼 큰 글자로 이미 보여주는 마지막 장면은 자막을 넣지 않는다 (`narration.slice(0, -1)`).

## 화면 배치 규칙

- 자막 영역(y 1400~1600)에는 3D 소품(금화 더미, 사람, 문, 쌓인 말풍선)을 두지 않는다. 겹치면 소품을 위로 올린다.
- 같은 문장이 자막과 3D 글자에 중복되면 3D 쪽 글자를 뺀다.
- 쇼츠 하단 약 20%(1600 이하)는 제목·설명 UI에 가려지므로 자막을 두지 않는다.

## 확인

- 자막이 나오는 프레임 5장 이상을 렌더링해서 글자 잘림, 두 줄 넘김, 소품 겹침을 본다 (`motion-6-verify-render`).
- 타이밍은 재생해서 봐야 안다. 사용자에게 어긋나는 문장과 정도(예: "0.3초 빨라요")를 받아 `Subtitles.tsx`의 `END_GAP`이나 `timeline.ts`를 고친다.
