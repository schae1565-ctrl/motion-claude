# 영상 편집 3단계: 확대·빨간 박스·블러

`videos/<slug>/2-motion/edit.json`의 `zoom`, `blur` 배열에 적고 `node scripts/edit-video.mjs <slug>`로 적용한다. **좌표는 원본 해상도 픽셀, 시간은 원본 기준 초**다.

## 좌표 구하기

1. 모음 이미지(`video-edit-1-ingest`)에서 대략의 위치를 잡는다. 타일 좌표 × (원본 가로 ÷ 타일 가로)가 원본 좌표다. 예: 5120 ÷ 640 = 8배.
2. 정확하게 하려면 해당 시각의 **원본 해상도 프레임을 잘라서** 눈으로 확인한다.
   ```powershell
   ffmpeg -hide_banner -loglevel error -y -ss <초> -i <raw 파일> -frames:v 1 -vf "crop=<w>:<h>:<x>:<y>,scale=<w/2>:-1" crop.png
   ```
   잘라낸 그림에서의 좌표 × (자른 배율)에 `x`, `y`를 더하면 원본 좌표다.
3. 박스에는 여유를 조금 둔다 (대상 크기보다 사방 10~20% 크게).

## 확대 + 빨간 박스 (`zoom`)

```json
{ "label": "키 생성 버튼", "start": 22.5, "end": 26.0, "x": 4070, "y": 940, "w": 270, "h": 140, "scale": 2.6 }
```

- 빨간 박스가 `x,y,w,h`에 그려지고, 화면이 그 중심으로 `scale`배 확대된다. 앞뒤 12프레임은 부드럽게 들어가고 나온다.
- 구간은 보통 3~5초. 말하는 내용과 화면 동작(클릭, 커서가 멈춘 곳)에 맞춘다.
- 화면 가장자리 대상은 확대 시 화면 밖으로 나가지 않도록 자동으로 안쪽으로 맞춰진다.
- **무엇을 강조할지는 말 내용에 따라 달라진다.** 말을 듣지 못했으면 화면 동작(클릭·입력·결과 표시)으로 고르고, 사용자에게 알려서 바꿀 수 있게 한다.

## 블러 (`blur`)

```json
{ "label": "API 키 (개인정보)", "start": 71.0, "end": 87.0, "x": 1980, "y": 1650, "w": 1160, "h": 130 }
```

- **개인정보는 나타나는 순간부터 사라지는 순간까지 전부** 덮는다. 앞뒤로 0.5초쯤 여유를 둔다. 확대 구간과 겹쳐도 블러가 먼저 적용된다.
- 가려야 하는 것: API 키·토큰·비밀번호, 이메일, 실명, 전화번호, 주소, 카드·계좌번호, 개인 URL. 모음 이미지를 훑어 빠진 곳이 없는지 본다.
- 일부만 가려진 키(끝 4자리 등)는 서비스에서 이미 마스킹한 것이므로 보통 그대로 둔다. 판단이 어려우면 사용자에게 묻는다.
- 같은 정보가 화면 여러 곳(대화상자, 토스트, 목록)에 나오면 모두 `blur`에 넣는다.

## 적용 뒤 반드시 확인

1. 결과 영상에서 블러 구간의 프레임을 뽑아 **글자가 읽히지 않는지** 눈으로 본다. 키가 읽히면 `sigma`(스크립트의 `gblur=sigma=45`)를 키우거나 박스를 넓힌다.
2. 확대 구간 프레임에서 빨간 박스가 대상에 맞는지 본다.
3. 개인정보 블러를 확인하지 못했으면 영상을 공유하지 않도록 사용자에게 알린다.
