# 캐릭터

영상에 반복해서 나오는 캐릭터(진행자, 화자, 마스코트)의 페르소나를 모아 둔다.
캐릭터 하나 = `characters/<slug>/` 폴더 하나. `<slug>`는 영문 소문자와 하이픈(`haejin-unnie`).

## 새 캐릭터 만들기

1. `_template/` 폴더를 통째로 복사해 `characters/<slug>/`로 이름을 바꾼다
2. 아래 순서로 채운다. 앞 파일이 정해져야 뒤 파일이 흔들리지 않는다
   1. `persona.md` — 누구인가 (정체성, 성격, 시청자와의 관계)
   2. `voice.md` — 어떻게 말하는가 (말투, 입버릇, 금지어, TTS)
   3. `visual.md` — 어떻게 보이고 움직이는가 (외형, 색, 표정, 모션)
   4. `samples.md` — 실제로 써 본 대사·장면 (검증용)
3. `samples.md`의 대사를 소리 내어 읽어 보고, 캐릭터답지 않은 문장이 나오면 1~3을 고친다

## 대본·씬 작업에서 쓰는 법

- 대본을 쓸 때 `persona.md`와 `voice.md`를 먼저 읽고, `senior-hook-script` 규칙과 함께 지킨다
- 시각화 표의 "사용할 컴포넌트"에는 `visual.md`의 표정·포즈 이름을 그대로 적는다
- 색은 `visual.md`에 `theme.ts` 토큰 이름으로 적는다. 새 색이 필요하면 `theme.ts`에 추가한다
