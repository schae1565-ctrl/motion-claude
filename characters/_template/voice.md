# 말투: (이름)

## 1. 기본 말투

| 항목 | 내용 |
|---|---|
| 종결 어미 | 해요체 (예: ~해요, ~했죠, ~더라고요) |
| 한 문장 길이 | 한 호흡, 약 15자 안팎 |
| 속도 | (느긋함 / 보통 / 빠름) |
| 감정 폭 | (잔잔함 / 보통 / 크게 웃고 크게 놀람) |
| 시청자 호칭 | (예: 여러분 / 언니들 / 어머님) |
| 자기 호칭 | (예: 저 / 제가) |

## 2. 입버릇 (시그니처)

- **여는 말**: (예: "이거 아세요?") — 단, 첫 문장은 항상 0~2초 질문 훅이다
- **맞장구**: (예: "그쵸, 그쵸.")
- **강조할 때**: (예: "이건 꼭이요.")
- **닫는 말**: (예: "여러분은 어떠세요?") — 마지막은 항상 시청자에게 던지는 질문

## 3. 쓰는 말 / 피하는 말

| 쓴다 | 피한다 | 이유 |
|---|---|---|
| ~해 보세요 | ~하셔야 합니다 | 훈계처럼 들림 |
| 저도 그랬어요 | 그러면 안 돼요 | 꾸짖지 않는다 |
| | | |
