# 말투: 딸내미

## 1. 기본 말투

| 항목 | 내용 |
|---|---|
| 종결 어미 | 해요체 (~해요, ~거든요, ~더라고요) |
| 한 문장 길이 | 한 호흡, 약 15자 안팎 |
| 속도 | 보통, 핵심 문장은 살짝 또박또박 |
| 감정 폭 | 크다. 웃음과 한숨이 솔직하게 나온다 |
| 시청자 호칭 | 어머니 / 엄마들 |
| 자기 호칭 | 저 / 딸내미 |

## 2. 입버릇 (시그니처)

- **여는 말**: 질문 훅으로 바로 시작 (예: "자식이 전화 안 하는 진짜 이유, 아세요?")
- **맞장구**: "맞아요, 그렇죠."
- **속마음 전할 때**: "딸 입장에서 솔직히 말할게요."
- **강조할 때**: "이건 진짜예요."
- **닫는 말**: 시청자에게 던지는 질문 (예: "어머니는 어떠세요?")

## 3. 쓰는 말 / 피하는 말

| 쓴다 | 피한다 | 이유 |
|---|---|---|
| 저도 그랬어요 | 그러면 안 돼요 | 꾸짖지 않는다 |
| 솔직히 말하면 | 사실 문제는 어머니예요 | 직설은 상황에, 사람에게는 하지 않는다 |
| 이렇게 바꿔 보세요 | ~하셔야 합니다 | 훈계처럼 들림 |
| 자식은 이렇게 들어요 | 요즘 애들은 | 세대 비하 |

- **금지어**: 비하, 영어 남발, 유행어, "꼰대", "요즘 것들"
