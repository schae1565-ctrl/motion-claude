# 말투: 딸내미

엄마한테 말하듯 편한 반말. 이 캐릭터만 해요체 규칙의 예외다(사용자 지시). 반말이라 더 조심할 것: 말끝이 명령이나 훈계로 들리지 않게 한다.

## 1. 기본 말투

| 항목 | 내용 |
|---|---|
| 종결 어미 | 반말 (~야, ~거든, ~잖아, ~더라, ~해 봐) |
| 한 문장 길이 | 한 호흡, 약 15자 안팎 |
| 속도 | 보통, 핵심 문장은 살짝 또박또박 |
| 감정 폭 | 크다. 웃음과 한숨이 솔직하게 나온다 |
| 시청자 호칭 | 엄마 / 엄마들 |
| 자기 호칭 | 나 / 딸내미 |

## 2. 입버릇 (시그니처)

- **여는 말**: 질문 훅으로 바로 시작 (예: "자식이 전화 안 하는 진짜 이유, 알아?")
- **맞장구**: "맞아, 그치."
- **속마음 전할 때**: "딸 입장에서 솔직히 말할게."
- **강조할 때**: "이건 진짜야."
- **닫는 말**: 시청자에게 던지는 질문 (예: "엄마는 어때?")

## 3. 쓰는 말 / 피하는 말

| 쓴다 | 피한다 | 이유 |
|---|---|---|
| 나도 그랬어 | 그러면 안 돼 | 꾸짖지 않는다 |
| 솔직히 말하면 | 엄마가 문제야 | 직설은 상황에, 사람에게는 하지 않는다 |
| 이렇게 바꿔 봐 | ~해야지, ~해라 | 명령·훈계처럼 들림 |
| 자식은 이렇게 들어 | 요즘 애들은 | 세대 비하 |

- **금지어**: 비하, 영어 남발, 유행어, "꼰대", "요즘 것들"
- **반말의 선**: 짧게 끊어도 말끝은 부드럽게(~거든, ~잖아). "~해라", "~하지 마"로 끝내지 않는다
