# 외형과 모션: 딸내미

## 1. 외형

| 항목 | 내용 |
|---|---|
| 형태 | 새 2D 일러스트 캐릭터 (SVG, 상반신) |
| 기본 컴포넌트 | 새로 만든다: `src/shared/ui/Ddalnaemi.tsx` (표정·포즈를 props로 받음) |
| 실루엣 특징 | 높게 묶은 말총머리 한 갈래 (멀리서도 알아볼 포인트) |
| 소품 | 무릎 위 폰, 어깨에 멘 에코백 (엄마 집 가는 길) |
| 체형·옷 | 둥근 얼굴, 단순한 도형. 베이지 니트 + 앞치마 없음 |

## 2. 색 (`theme.ts` 토큰)

| 부위 | 토큰 | 비고 |
|---|---|---|
| 얼굴·피부 | `theme.good` | 기존 값 사용 |
| 머리 | `theme.text` | 기존 값 사용 |
| 옷(니트) | `theme.bgWarm` | 기존 값 사용 |
| 포인트(머리끈·볼터치) | `theme.heart` | 기존 값 사용 |
| 말풍선 | `theme.bgWarm`, 글자 `theme.text` | 기존 `SpeechBubble` 재사용 |

새 색은 아직 필요 없다. 필요해지면 여기 적고 `theme.ts`에 추가한다.

## 3. 표정 세트

| 이름 | 쓰는 순간 | 비고 |
|---|---|---|
| neutral | 설명할 때 | 눈 점, 입 작은 곡선 |
| smile | 인사, 응원, 대신 할 말 | 눈 호선, 입 크게 |
| worry | 속마음, 하지 말 말의 결과 | 눈썹 팔자, 입 일자 |
| surprise | 반전 | 눈 크게, 입 동그라미 |
| sulk | 직설 날릴 때 | 눈 반쯤 감고 한쪽 입꼬리 |

## 4. 포즈·동작 (`motion.ts` 스프링만 사용)

| 이름 | 쓰는 순간 | 모션 프리셋 |
|---|---|---|
| 등장 | 첫 등장 | `pop` |
| 끄덕임 | 공감 | `soft` (머리 기울임) |
| 놀람 | 반전 | `shake` |
| 손짓 | 짚어 줄 때 | `soft` (팔 올림) |
| 퇴장 | 마무리 | `soft` (아래로 내려감) |

프리셋 이름은 구현 전에 `src/shared/motion.ts`의 실제 이름과 맞춰 확인한다.

## 5. 화면 배치 (1080×1920)

- **기본 위치**: 화면 하단 왼쪽 1/3, 상반신, 높이 약 520px
- **자막과의 관계**: 하단 자막은 캐릭터 위쪽 영역. 말풍선은 캐릭터 오른쪽 위
- **다른 인물과 함께 나올 때**: 엄마 `PersonDot`은 오른쪽, 딸내미보다 약간 작게
