# 문장별 시각화 표 (승인 대기)

화면: 1080×1920 세로. 글자는 크게(본문 최소 64px), 한 화면에 한 메시지.
"하지 말 말"은 회색 말풍선에 붉은 X, "자식의 속마음"은 푸른 회색 생각 구름, "대신 할 말"은 따뜻한 색 말풍선에 초록 체크로 대비한다.

## 후킹 구간 (0~5초)

첫 프레임(0프레임)부터 질문 글자가 화면에 보인다. 페이드인으로 시작하지 않고, 처음 10프레임 안에 크기만 살짝 튀어 오른다.

| # | 문장 | 화면 구성 | 모션 | 사용할 컴포넌트 |
|---|---|---|---|---|
| 1 | 용돈은 오는데, 전화는 0건. 왜일까요? | 위쪽에 초록색 "용돈 입금 500,000원" 알림 카드, 가운데에 "통화기록 0건"(숫자 0은 붉은색 260px), 그 아래 "왜일까요?"(96px), 맨 아래에 두 원(엄마·자녀) | 0프레임부터 "통화기록 0건"이 보이고 10프레임 동안 스프링으로 살짝 커졌다 자리 잡음. 입금 카드가 6프레임에 튀어나오고, "왜일까요?"가 20프레임에 떠오르며 두 원이 멀어지기 시작 | kit `HookTitle`, ui `NotificationCard`, ui `PersonDot` |
| 2 | 사랑해서 한 이 세 마디가, 마음의 문을 닫아요. | 질문이 위로 올라가 작아지고, 가운데에 하트 말풍선 세 개가 "?"로 가려진 채 놓인다. 마지막에 문이 쾅 닫히는 그림 | 말풍선이 차례로 튀어나오고, "마음의 문"에서 문 아이콘이 닫힌다 | kit `HookTitle`, ui `SpeechBubble`(hidden), ui `DoorIcon` |

## 본문 구간 (항목마다 세 박자)

화면에는 위에 숫자 배지, 가운데에 엄마 말풍선, 그 아래에 자녀 원(`PersonDot`)과 생각 구름이 놓인다.

| # | 문장 | 화면 구성 | 모션 | 사용할 컴포넌트 |
|---|---|---|---|---|
| 3 | 첫 번째. "내가 너 때문에 어떻게 살았는데." | 숫자 배지 1, 가운데 회색 말풍선 속 인용문 | 가려져 있던 말풍선이 열리며 인용문이 나타나고, 배지가 튀어나온다 | ui `NumberBadge`, ui `SpeechBubble`(bad) |
| 4 | 자식은 이렇게 들어요. "아, 나는 갚아야 할 빚이구나." | 아래에 자녀 원이 나타나고 푸른 회색 생각 구름 속에 속마음. 엄마 말풍선은 흐려진다 | 생각 구름이 작은 점 세 개에서 커지며 떠오르고, 자녀 원이 고개를 숙이듯 살짝 내려간다 | ui `PersonDot`, ui `ThoughtBubble` |
| 5 | 대신 이렇게요. "너 키우면서 나도 행복했어." | 회색 말풍선에 붉은 X가 그어진 뒤 따뜻한 색 말풍선으로 바뀌고 초록 체크. 생각 구름은 밝은 색으로 바뀌며 자녀 원이 웃는 얼굴 | X가 두 획으로 그려지고, 말풍선이 뒤집히듯 바뀐 뒤 체크가 그려진다. 구름 색이 밝아진다 | ui `StrikeMark`, ui `SpeechBubble`(good), ui `CheckMark`, ui `ThoughtBubble` |
| 6 | 두 번째. "다 너 잘되라고 하는 말이야." | 3번과 같은 구성, 배지 2 | 3번과 같음 | ui `NumberBadge`, ui `SpeechBubble`(bad) |
| 7 | 자식은 이렇게 들어요. "또 시작이네. 내 얘기는 안 듣잖아." | 4번과 같은 구성 | 4번과 같음 | ui `PersonDot`, ui `ThoughtBubble` |
| 8 | 대신 이렇게요. "엄마 생각은 이런데, 넌 어때?" | 5번과 같은 전환 | 5번과 같음 | ui `StrikeMark`, ui `SpeechBubble`(good), ui `CheckMark` |
| 9 | 세 번째. "누구네 아들은 벌써…" | 3번과 같은 구성, 배지 3 | 3번과 같음 | ui `NumberBadge`, ui `SpeechBubble`(bad) |
| 10 | 자식은 이렇게 들어요. "난 늘 부족한 자식이구나." | 4번과 같은 구성 | 4번과 같음 | ui `PersonDot`, ui `ThoughtBubble` |
| 11 | 대신 이렇게요. "요즘 바쁘지? 고생이 많다." | 5번과 같은 전환, 옆에 작은 하트 | 5번과 같음, 마지막에 하트가 살짝 뛴다 | ui `StrikeMark`, ui `SpeechBubble`(good), ui `CheckMark` |

## 마무리 구간

| # | 문장 | 화면 구성 | 모션 | 사용할 컴포넌트 |
|---|---|---|---|---|
| 12 | 가르치지 말고, 들어주세요. 마음이 훨씬 가까워져요. | 1번의 두 원이 다시 나오고 배경이 따뜻한 색으로 밝아진다. "가르치기"를 지우고 "들어주기"로 바꿔 쓴다 | 두 원이 천천히 가까워져 겹치고, 배경색이 서서히 밝아진다 | kit `ClosingCard`, ui `PersonDot`, ui `Caption` |
| 13 | 자식 마음에 쌓인 이 말들, 지금 몇 개일까요? | 질문을 크게(96px 이상) 보여 주고, 아래에 "캡처해서 써 보세요" 카드(카메라 아이콘과 대신 할 말 3가지). 음성 없이 화면 문구로만 캡처를 유도하고, 음성이 끝난 뒤 2.5초 더 유지가 나란히 놓인다. 따뜻한 배경 유지 | 질문이 떠오른 뒤 체크박스 세 개가 차례로 깜빡이며 "나도 했나?" 돌아보게 한다. 마지막 프레임은 질문이 그대로 남는다 | kit `ClosingCard`, ui `NumberBadge`, ui `CheckBox` |

## 새로 만들 공용 컴포넌트

`src/shared`가 아직 비어 있어 아래는 모두 새로 만든다. 다른 영상에서도 쓸 수 있게 `src/shared`에 둔다.

- `theme.ts`: 배경(따뜻한 아이보리), 본문(진한 갈색), 하지 말 말(회색·붉은색), 속마음(푸른 회색), 대신 할 말(살구색·초록색)
- `motion.ts`: 부드러운 등장, 튀어나옴, 천천히 이동 — 스프링 3종
- ui: `SpeechBubble`(bad / good / hidden), `ThoughtBubble`, `NumberBadge`, `StrikeMark`, `CheckMark`, `CheckBox`, `Caption`, `PersonDot`, `DoorIcon`, `NotificationCard`(입금 알림)
- kit: `HookTitle`, `ClosingCard`
