# 3D 모션그래픽 시각화 표 (승인 대기)

기존 2D 장면을 3D로 바꾼다. 장면 구성은 이전 목록과 달라도 되지만 **러닝타임은 그대로**다.

- 총 1286프레임(42.9초). 음성은 40.35초에 끝나고, 마지막 2.5초는 캡처용으로 화면만 유지한다
- 장면 경계는 음성에서 추정한 값 그대로 쓴다: 0, 91, 185, 269, 375, 479, 551, 663, 758, 828, 930, 1020, 1121, 끝 1286
- 화면 1080×1920, 30fps. 글자는 선명하게 보이도록 3D 위에 겹치는 2D 글자로 유지한다
- 3D는 `three` 기본 도형(둥근 상자, 구, 원기둥, 토러스)만 쓴다. 외부 3D 파일은 쓰지 않는다
- 색은 `theme.ts`, 움직임은 `motion.ts`의 스프링만 쓴다. 카메라도 스프링으로 움직인다

## 공통 3D 연출

- **카메라**: 장면마다 살짝 다른 각도로 천천히 다가가거나 돈다 (정면 고정 없음)
- **조명**: 따뜻한 주광 하나 + 부드러운 보조광. 바닥에 옅은 그림자를 둔다
- **재질**: 무광 점토 느낌. 둥근 모서리로 부드럽고 친근하게 만든다
- **인물**: 엄마(주황 구)와 자녀(파란 구). 눈과 입이 있고, 표정이 바뀐다

## 새로 만들 코드

- `src/shared/three/`: 공용 3D 요소
  - `Stage`: 카메라·조명·바닥 그림자를 한 번에 설정하는 3D 무대
  - `RoundedSlab`: 둥근 말풍선·카드 슬래브 (말풍선 3종: 회색, 따뜻한 색, 푸른 구름)
  - `Person3D`: 엄마·자녀 구(눈·입, 표정 3종)
  - `Coin`, `CoinRain`, `Door3D`, `Phone3D`, `Check3D`, `XMark3D`, `HeartBurst`
  - `useCamera`: 장면 시작 프레임 기준으로 카메라를 스프링으로 움직이는 훅
- `src/videos/adult-children-talk/`의 `Hook.tsx`, `Item.tsx`, `Closing.tsx`를 3D 버전으로 교체한다. 기존 2D 파일은 `2d/` 폴더로 옮겨 두고 지우지 않는다
- `motion.ts`: 3D용 스프링(무거운 낙하, 가벼운 떠오름)을 추가한다

## 알아두실 점

- 3D 렌더링은 2D보다 훨씬 느리다. 전체 렌더링은 10분 안팎이 걸릴 수 있다
- 3D 글자는 한글 폰트 파일이 필요해서 쓰지 않고, 글자는 2D로 겹친다
- 3D 렌더링이 되는 것은 확인했다 (큐브 한 장 테스트, `--gl=angle` 설정 추가)
