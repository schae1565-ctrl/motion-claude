# 레퍼런스 분석: Claude Motion Reel 2026

- 원본: https://cdn.revid.ai/static/claude-motion-graphics/stephanlivera-2103315922098470926.mp4
- 규격: 1920×1080, 60fps, 15.06초, 음악만 있음 (말소리 없음)
- 성격: "모든 프레임을 코드로 만든" 모션 디자이너 쇼릴. 7개 챕터로 기법을 하나씩 보여 준다
- 캡처: `sheet_01~04.png` (0.25초 간격, 한 장에 4초), `easing-frame.png`, `end-frame.png`, `transition-30fps.png`

## 1. 핵심 구조: 음악 박자 = 편집 격자

128 BPM → 1박 = 0.469초, 1마디(4박) = 1.875초, **8마디 = 15초**.
씬이 정확히 **1마디마다** 바뀌고, 화면 오른쪽 아래 `□■□□ BAR 3/8` 표시가 박자를 그대로 보여 준다.
모든 타이밍을 프레임 숫자가 아니라 "몇 마디 몇 박"으로 정해서 리듬감이 생긴다.

| 마디 | 시간 | 챕터 | 배경 | 내용 |
|---|---|---|---|---|
| 1 | 0.0–1.9 | 01 IDENTITY | 검정 | 작은 원 → 점 → 방사형 선이 뻗어 별표(asterisk) 로고. 원형 글자가 돌며 둘러쌈. 끝에 흰 점 하나로 수축 |
| 2 | 1.9–3.4 | (identity 이어서) | 코랄 | 점에서 원형으로 배경 확장. `CLAUDE` 글자 폭이 넓게→좁게 변하며(가변 폭) 모션 블러. 이탤릭 세리프 `motion designer`가 아래서 올라옴. 끝에 글자가 왼쪽부터 점으로 쪼그라들며 퇴장 |
| 3 | 3.4–5.6 | 02 EASING | 크림 | 점들이 날아와 6줄로 정렬. "같은 거리·같은 시간"을 linear / ease-in-out / expo-out / back-out / elastic / bounce 로 비교. 공 뒤에 잔상(ghost)과 눈금. 끝에 공 6개가 한 점으로 합쳐짐 |
| 4 | 5.6–7.7 | 03 MORPHING | 파랑 | 가운데 흰 도형이 원→삼각형→별→사각형으로 모핑, 빨간 외곽선 잔상. 둘레 12개의 작은 도형도 같이 모핑하며 회전 |

| 6 | 9.4–11.3 | 05 DEPTH | 검정 | 점으로 된 3D 평면이 물결 → 구 → 항아리 → 도넛 모양으로 변형하며 회전 (점 578개, 원근 투영) |
| 7 | 11.3–13.2 | 06 KINETIC TYPE | 매 박자 색 바뀜 | **박자마다 하드컷**: EASE / IN. / EASE / OUT. / NEVER / NEVER 반복 패턴 / LINEAR. 단어 끝 마침표는 코랄 원 |

## 2. 씬 연결 방식 — "점 하나로 이어 붙이기"

전환이 대부분 컷이 아니라 **모든 요소가 점 하나로 모였다가 그 점이 다음 화면으로 퍼지는** 방식이다.

- 별표 로고 → 흰 점 → 점이 원으로 커지며 코랄 배경
- CLAUDE 글자 → 글자마다 점으로 줄어듦 → 사선 와이프로 크림 화면, 점들이 다음 씬의 공이 됨
- 공 6개 → 파란 점 하나 → 파란 배경
- 사각형 → 타일 → 패턴 → 가운데로 빨려 들어가 점 격자 → 3D 점 구름

시선이 한 점에 고정된 채 화면이 바뀌므로, 장면이 많아도 정신없지 않다.
→ 우리 영상에 바로 쓸 만한 가장 큰 교훈.

## 3. 디자인 시스템

**색 (5색 고정)**: 거의 검정 `#0D0D0F` · 따뜻한 크림 `#F0EBE3` · 코랄 레드 `#EF4B3A` · 일렉트릭 블루 `#2B2BF0` · 라임 `#E0FF4A`.
씬마다 배경색을 통째로 바꾸고, 강조색은 항상 나머지 중 하나만 쓴다. (추출값은 근사치)

**글꼴 (3종 대비)**
- 아주 넓은 굵은 산세리프(확장 그로테스크) — 큰 단어
- 이탤릭 세리프 — 보조 문구 (`motion designer`, `Six ways to get from A to B.`)
- 고정폭(mono) 대문자, 자간 넓게 — 라벨·숫자·HUD

**HUD 프레임** (모든 씬 위에 고정)
- 네 모서리 ㄱ자 괄호
- 왼쪽 위 `CLAUDE  MOTION REEL — 2026`, 오른쪽 위 `02 — EASING` (챕터 번호)
- 왼쪽 아래 타임코드 `00:00:04:24` + `60 FPS`, 아래쪽 진행 막대가 점점 길어짐
- 오른쪽 아래 `128 BPM □■□□ BAR 3/8` (박자 칸이 하나씩 채워짐)
- 씬 안에도 "기술 캡션"이 붙음: `SAME DISTANCE · SAME DURATION (0.94s)`, `TRUCHET × 153 · 3 WAVES`, `VERTICES 578 · FOCAL 1000`

**질감**: 아주 옅은 필름 그레인. 빠른 물체는 진행 방향으로 늘어난 타원(모션 블러).

## 4. 기법 목록과 Remotion 구현 메모

| 기법 | 보이는 모습 | Remotion에서 만드는 법 |
|---|---|---|
| 박자 격자 | 1마디마다 씬, 1박마다 컷 | `const beat = fps*60/bpm` 상수로 모든 `<Sequence from>`을 계산 |
| 선 그리기 등장 | 별표 선이 중심에서 뻗음 | SVG `strokeDasharray` + `strokeDashoffset`을 스프링 값으로 |
| 원형 글자 회전 | 로고 둘레 글자 | SVG `<textPath>` + 프레임 비례 `rotate` |
| 가변 폭 글자 | CLAUDE 폭이 늘었다 줄어듦 | 가변 글꼴의 `fontVariationSettings: 'wdth'` 또는 `scaleX` 스프링 |
| 글자→점 퇴장 | 글자가 차례로 점이 됨 | 글자별 `scale` 줄이며 원(`borderRadius:50%`)으로 교체, 글자마다 delay |
| 모션 블러 | 빠른 공이 타원으로 늘어남 | 속도(이번 프레임−이전 프레임 위치)에 비례해 `scaleX` 늘리고 `scaleY` 줄임. 또는 `@remotion/motion-blur`의 `<CameraMotionBlur>` |
| 잔상(ghost trail) | 공 뒤 흐린 원 3개 | 같은 컴포넌트를 frame−3, −6, −9로 그리고 투명도 낮춤 |
| 이징 비교 | 6가지 곡선 | `Easing.linear/inOut/out(exp)/back/elastic/bounce` + `interpolate` (단, 우리 규칙상 `motion.ts`에 프리셋으로 추가해서 사용) |
| 도형 모핑 | 원→삼각형→별→사각형 | `@remotion/paths`의 `interpolatePath`, 또는 같은 개수의 점으로 샘플링 후 보간 |
| Truchet 패턴 | 4분원 호 타일 | 격자마다 시드 난수로 방향 결정, 거리 기반 파동 `sin(dist - frame*k)`로 색·회전 |
| 3D 점 구름 | 구·항아리·도넛 | 점 좌표를 직접 계산해 원근 투영(2D) 또는 `@remotion/three`의 `<points>` |
| 키네틱 타이포 | 박자마다 단어·배경 교체 | `<Series>`로 1박 길이 시퀀스 나열, 단어 끝 원형 마침표에 `pop` |
| 반복 외곽선 패턴 | NEVER가 화면 가득 흐름 | 외곽선 글자(`WebkitTextStroke`) 여러 줄, 줄마다 반대 방향 `translateX` |
| 파티클 | 마지막 로고 주변 점들 | 시드 고정 난수로 위치·속도 생성 (`random()` from remotion) |

## 5. 우리 시니어 쇼츠(1080×1920, 30fps)에 옮길 때

**가져올 것**
1. **점 이어 붙이기 전환** — 씬 끝 요소를 점으로 모으고 그 점을 다음 씬 배경으로 키운다. `src/shared/kit`에 `DotBridge` 같은 공용 전환으로 만들 만하다
2. **편집 격자** — BPM 대신 음성 문장 경계를 격자로 쓴다. 문장 시작마다 "강세 동작" 하나만
3. **씬마다 배경색 통째로 바꾸기** — 대본 단락이 바뀌는 걸 색으로 알려 준다 (색은 `theme.ts`에 추가 후 사용)
4. **큰 굵은 글자 + 이탤릭 보조 문구** 대비 — 핵심 단어는 크게, 설명은 작고 부드럽게
5. **모션 블러·잔상** — 빠른 이동에만 살짝. 움직임이 "빨라 보이는" 효과
6. **이징 프리셋 추가** — 지금 `motion.ts`는 soft/pop/slow/shake 4개. back-out(살짝 넘쳤다 돌아옴), expo-out(확 나왔다 천천히 멈춤)에 해당하는 스프링 프리셋을 추가하면 표현 폭이 넓어진다

**덜어낼 것**
- 1박(0.47초)마다 하드컷은 60대 시청자에게 너무 빠르다 → 한 단어 최소 1초 이상
- HUD의 작은 mono 글씨(타임코드·BPM)는 세로 화면·휴대폰에서 안 읽힌다 → 챕터 번호와 진행 막대 정도만
- 라임·일렉트릭 블루 같은 강한 색은 한 영상에 한두 번 포인트로만
- 3D 점 구름·Truchet은 정보 전달보다 "기술 과시"용. 시니어 영상에선 배경 질감 정도로만

## 6. 한 줄 요약

> 박자로 시간을 나누고, 점 하나로 장면을 이어 붙이고, 색·글꼴·HUD를 5색·3종·1틀로 묶어서 — 기법이 7가지나 되는데도 한 작품처럼 보이게 만든 영상.
